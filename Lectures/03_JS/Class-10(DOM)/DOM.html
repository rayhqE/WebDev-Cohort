DOM — Document Object Model

1. What is DOM?

  • DOM = Document Object Model.
  • It represents an HTML document as a tree of objects/nodes.
  • JavaScript uses the DOM to access and manipulate HTML elements.

2. window & document

  • window = global object provided by the browser.
  • document = represents the current HTML page.
window
  ↓

  ↓
HTML DOM tree

Usually we directly use document to manipulate the webpage.

3. Types of DOM Nodes

  • Element Node → HTML elements like <div>, <p>, <h1>
  • Text Node → Text inside an element
  • Comment Node → HTML comments
  • Attribute Node → Attributes like id, class, src, href
  • Document Node → The document itself
<p class="para">Hello</p>

Element → p
Attribute → class="para"
Text → "Hello"

4. Selecting Elements

getElementById()

const heading = document.getElementById("heading1");

Selects one element using its ID.

querySelector()

const heading = document.querySelector("#heading1");

const para = document.querySelector(".para");

const firstLi = document.querySelector("#list-container li");

Returns the first matching element.

querySelectorAll()

const listItems = document.querySelectorAll("#list-container li");

Returns all matching elements.

5. Creating Elements

const button = document.createElement("button");

Creates a new HTML element, but it is not visible until added to the DOM.

6. Adding Elements

document.body.appendChild(button);

Adds the newly created element to the page.

button.innerText = "Press";

Sets the text inside the button.

7. innerHTML

ul.innerHTML += "<li>item 4</li>";

Adds HTML content inside the element.

Note: innerHTML works with HTML strings, while textContent/innerText deals with text.

8. Style Manipulation

element.style.backgroundColor = "red";

Directly changes an element's inline CSS.

document.body.style.backgroundColor = "red";

9. classList

Used to manipulate CSS classes using JavaScript.

add()

button.classList.add("button");

Adds a class.

remove()

button.classList.remove("button");

Removes a class.

toggle()

document.body.classList.toggle("dark");

If the class exists → removes it.
If the class doesn't exist → adds it. 

document.body.classList.toggle("dark");
// true → class added
// false → class removed

10. Event Listeners

button.addEventListener("click", () => {
  document.body.classList.toggle("dark");
});

This runs the function whenever the button is clicked.

Common events:

  • click
  • input
  • change
  • submit
  • mouseover
  • keydown

11. Example: Create Button Dynamically

const button = document.createElement("button");

document.body.appendChild(button);

button.innerText = "Press";

button.classList.add("button");

button.addEventListener("click", () => {
  document.body.classList.toggle("dark");
});
